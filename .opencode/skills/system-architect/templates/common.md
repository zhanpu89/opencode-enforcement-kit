# SAD 文档通用骨架

> 通用骨架（25 章 + 头部 + 尾部），所有端类型共享。端专属章节见 `templates/end-specific.md`。

## 文档头部格式

```
# {项目名} — 系统架构设计文档
**文档编号**：SAD-YYYYMMDD-NNN　**版本**：v1.0.0　**状态**：🟡 草稿
**创建日期**：YYYY-MM-DD　**最后更新**：YYYY-MM-DD
**作者**：[姓名]　**审核人**：[姓名/待定]　**关联文档**：{PRD文档路径 / 无}
```

## 文档类型与章节说明

> **后端**（`_SAD.md` 或 `_SAD_后端.md`）：全部章节 1-25 + 变更记录。
> **前端**（`_SAD_前端.md`）：1-6、F1-F6、22-25。
> **小程序**（`_SAD_小程序.md`）：1-6、M1-M6、22-25。
> **概览**（`_SAD_概览.md`）：仅 1-3 + 端类型声明，≤ 500 字。

## 后端文档章节列表

1. 文档头部　2. 目录　3. 执行摘要　4. 需求分析　5. 系统架构　6. 技术栈
7. 数据库设计　8. API 设计　9. 模块设计　10. 特殊集成设计 ← 仅区块链/支付/文件存储时包含
11. 缓存策略　12. 消息队列设计　13. 安全设计　14. 性能优化　15. 可扩展性设计
16. 监控和告警　17. 部署架构　18. 灾难恢复　19. 成本分析　20. 风险评估
21. 实现路线图　22. 开发指南　23. 测试策略　24. 名词解释与缩写　25. 附录
26. 变更记录 ← **必须是最后一节**

> **粒度边界**：SAD 层写核心表名+端点列表+模块划分，不写完整 DDL/OpenAPI/伪代码（由 task-decomposer 生成）。

## 输出路径规则

```
doc/arch/{项目名}_SAD.md              # 纯后端
doc/arch/{项目名}_SAD_后端.md          # 含前端/小程序
doc/arch/{项目名}_SAD_前端.md          # Web 前端
doc/arch/{项目名}_SAD_小程序.md        # 微信小程序
doc/arch/{项目名}_SAD_概览.md          # 多端并存时
doc/arch/tech-stack.json              # 所有场景均生成
```

文件名使用中文项目名，不含日期、不含版本号。

## 章节详细定义

### 1. 文档头部
见上方"文档头部格式"。

### 2. 目录
根据文档中实际存在的章节自动生成。

### 3. 执行摘要
- 系统概述、核心架构特点（2-3 个关键决策）、技术栈概览、关键约束与风险

### 4. 需求分析
- 功能需求（引用 PRD）
- **非功能需求（必须量化）**：并发、响应时间（P99/P95）、可用性、数据保留
- 约束条件

### 5. 系统架构
- 高层架构图（ASCII / 文字描述）
- 组件职责、服务边界、核心数据流、集成点

### 6. 技术栈
每项须包含：是什么、为什么选它、为什么不选其他（1-2 备选）、已知权衡。

### 7. 数据库设计
> SAD 粒度：核心表名 + 关键字段 + ER 关系 + 索引策略概述。DDL 由 task-decomposer 生成。
- 数据库选型、核心表清单、ER 关系、索引策略、分区/分表策略

### 8. API 设计
> SAD 粒度：端点列表 + HTTP 方法 + 功能描述 + 认证方案。完整 OpenAPI 由 task-decomposer 生成。
- API 架构风格、主要端点列表、认证与授权、限流策略、错误处理规范

### 9. 模块设计
> SAD 粒度：模块划分 + 职责 + 依赖关系。伪代码由 task-decomposer 生成。
- 核心模块划分、模块职责、依赖关系图、关键接口定义（接口名 + 入参 + 出参）

### 10. 特殊集成设计
> 仅当涉及区块链/支付/文件存储时包含。规范参见 `resources/db-security-integration.md`。
**区块链**：上链策略、智能合约、哈希计算、异步上链流程、节点规划、验证流程。
**支付**：时序图（含回调）、幂等性、退款流程、签名验证。
**文件存储**：Bucket 结构、直传 vs 服务端转发、预签名 URL TTL、文件哈希。

### 11. 缓存策略
- 缓存层选型（Redis / 本地缓存）、缓存键设计、失效策略（TTL / 主动失效）、热数据识别

### 12. 消息队列设计
- MQ 选型、消息类型与 Topic、消费者组、错误处理和重试策略

### 13. 安全设计
> 逐项覆盖 `resources/db-security-integration.md` 清单 + Overlay 安全节。
- 认证方案、授权模型（RBAC）、敏感数据加密、API 安全、审计日志、合规

### 14. 性能优化
- 数据库优化（索引、读写分离）、缓存策略、异步处理、CDN

### 15. 可扩展性设计
- 水平扩展（无状态、Session 外置）、垂直扩展上限、数据库扩展、服务拆分路径

### 16. 监控和告警
- 关键指标（QPS、P99、错误率、CPU/内存）、日志策略、告警规则、监控工具

### 17. 部署架构
- 环境划分、容器化策略（Docker / K8s）、CI/CD、配置管理

### 18. 灾难恢复
- 备份策略、RTO、RPO、故障转移策略

### 19. 成本分析
- 基础设施成本估算、开源 vs 商业对比、成本优化建议

### 20. 风险评估
| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|---------|
| 技术风险 | 高/中/低 | 高/中/低 | ... |

### 21. 实现路线图
- MVP → 第二阶段 → 第三阶段（优化和扩展）+ 时间估计

### 22. 开发指南
- 项目结构、编码规范（参照 `resources/overlays.md`）、本地开发环境搭建

### 23. 测试策略
- 单元测试覆盖率、集成测试场景、性能测试基准、安全测试要点

### 24. 名词解释与缩写
定义文档中使用的所有技术术语和缩写。

### 25. 附录
相关文档链接、参考资料。

## 版本号变更规则

| 段位 | 触发条件 |
|------|---------|
| MAJOR | 架构方向根本性变化 |
| MINOR | 新增/删除章节，技术选型调整 |
| PATCH | 局部修正、评审小改、错别字 |

**变更类型标记：** 🆕 新建→v1.0.0 | 🐛 修正→PATCH | ✏️ 修改→PATCH | ➕ 新增→MINOR | 🗑️ 删除→MINOR | 🔄 重构→MAJOR

**强绑定：** 头部"版本"= 变更记录末行版本；"最后更新"= 末行日期。

## 文档尾部（变更记录）

每份架构文档的**最后一节**：

```markdown
## 变更记录

| 版本 | 日期 | 变更类型 | 变更内容摘要 | 变更人 |
|------|------|---------|------------|--------|
| v1.0.0 | YYYY-MM-DD | 🆕 新建 | 初始版本 | [作者] |
```
