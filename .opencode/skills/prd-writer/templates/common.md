# 通用章节骨架

> **用途**：本文件是所有端类型（后端 / 前端 / 小程序）PRD 模板的共享骨架片段。
> ⚠️ **内容规则（强制）**：
> - 【R-001】禁止出现任何技术性描述（框架、语言、数据库、API 协议、部署方式等）
> - 【R-002】所有描述必须是**业务语言**：描述"做什么"和"为什么"
> - 【R-003】违反 R-001 的内容一律删除
